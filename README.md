# AI Resume Analyzer

A web-based application that analyzes resumes using Natural Language Processing (NLP) techniques and compares them with job descriptions.

## Features
- Calculates resume-job match score
- Identifies missing skills
- Provides suggestions for improvement

## Technologies Used
- Python
- Machine Learning (TF-IDF, Cosine Similarity)
- Streamlit

## How to Run
1. Install dependencies
2. Run: streamlit run app.py
